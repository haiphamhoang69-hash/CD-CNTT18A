# BÀI 1: LÀM QUEN VỚI NODE.JS

## 1. Mục tiêu
- Cài đặt Node.js.
- Kiểm tra phiên bản Node.js và npm.
- Tạo và chạy chương trình Hello World bằng Node.js.

## 2. Kiểm tra phiên bản Node.js và npm

Mở Terminal hoặc CMD và nhập:

```bash
node -v
npm -v
```

Kết quả:

```text
v26.13.0
11.20.0
```

## 3. Tạo chương trình hello.js

Tạo file `hello.js` và nhập code:

```javascript
console.log("Hello World!");
console.log("Toi dang hoc Node.js va MongoDB.");
console.log("Node.js hoat dong thanh cong!");
```

## 4. Cách chạy chương trình

Mở Terminal tại thư mục chứa file `hello.js`, nhập lệnh:

```bash
node hello.js
```

## 5. Kết quả chạy chương trình

```text
Hello World!
Toi dang hoc Node.js va MongoDB.
Node.js hoat dong thanh cong!
```

## 6. Kết luận

Đã cài đặt Node.js thành công, kiểm tra được phiên bản Node.js và npm, đồng thời chạy thành công chương trình Hello World.
